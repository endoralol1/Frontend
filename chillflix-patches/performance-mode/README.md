# Performance mode (Browse Settings)

Opt-in toggle for lower-end PCs. Default **off**.

## Always on (everyone)
- Starfield static
- Moon glow / aurora / wave / glow orbs off
- No site-wide 125% zoom
- Film grain off
- Frosted-glass (`backdrop-filter`) off

## Performance mode only
- Shiny animated card titles off
- Card hover trailers off
