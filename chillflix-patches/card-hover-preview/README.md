# Card hover / long-press trailer preview

Desktop (≥992px): hover expands the card **to the right** and plays an HTML5 trailer.

Phone (&lt;992px): **long-press (~420ms)** expands **to the right** (`min(88vw, 22rem)`) and plays the trailer; tap outside to dismiss. Quick tap still opens the title. Disabled in Performance mode.

Live: `card-hover-preview.js/css?v=20260813-touch-expand2`
