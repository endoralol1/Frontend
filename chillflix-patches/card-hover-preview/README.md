# Card hover / long-press trailer preview

Desktop (≥992px): hover delay ~120ms expands card and plays HTML5 trailer.

Phone (&lt;992px): **long-press (~420ms)** plays trailer in-place on the card (no width expand). Tap outside to dismiss. Quick tap still opens the title. Disabled in Performance mode.

Live assets: `card-hover-preview.js/css?v=20260813-touch-preview1`
